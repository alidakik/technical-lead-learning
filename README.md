# Technical Lead Learning

A progressive daily curriculum for leading a startup engineering ecosystem across SaaS, backend, frontend, AI, hardware, cloud, DevOps, and QA.

## Current lesson

[Day 01 — Decision Rights & Delegation](lessons/day-001-decision-rights.html)

## Site

The repository contains a dependency-free static site. GitHub Actions deploys the `main` branch to GitHub Pages.

Each new lesson should include:

- a single focused topic;
- the standard lesson structure;
- a realistic startup example;
- role boundaries;
- questions, warning signs, and a next-day action;
- an entry on the landing page and progress count update.

Progress completion is stored locally in the reader's browser.
